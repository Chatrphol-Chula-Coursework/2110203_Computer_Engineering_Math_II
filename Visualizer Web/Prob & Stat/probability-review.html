01 Probability vs Statistics — ทิศทางกลับกัน

Probability รู้โมเดลแล้วถามว่าข้อมูลจะออกมาแบบไหน · Statistics เห็นข้อมูลแล้วถามย้อนว่าโมเดล (พารามิเตอร์) น่าจะเป็นอะไร ทั้งวิชาส่วนนี้คือการเดินจากขวาไปซ้ายของรูปนี้ให้เป็น

Probabilityรู้ P(H) = 0.7

เหรียญเอียง โยน 10 ครั้ง — โอกาสได้หัว พอดี 6 ครั้ง เท่าไร?
P(X = 6) = C(10,6) (0.7)6(0.3)4 ≈ 0.200

Statisticsไม่รู้ P(H) = ?

เห็นผล H T H H T H H T H T (หัว 6 จาก 10) — ประมาณ P(H) ได้เท่าไร และเชื่อได้แค่ไหน? → คำตอบตามสัญชาตญาณ p̂ = 6/10 = 0.6 ซึ่งจะพิสูจน์ด้วย MLE ในหน้า Estimation

สถิติเอาไปทำอะไร

  • Experimental design — ออกแบบการเก็บข้อมูลให้ใช้ได้จริง (A/B testing)
  • Summary — สรุปข้อมูลจาก poll / แบบสอบถาม
  • Inference — ใช้ข้อมูลอนุมานพารามิเตอร์ของโมเดล

Motivation จากสไลด์: ยา COVID ใช้ได้ไหม?

ตาราง 1: ยา A ตาย 9/40 = 22.5% · ไม่ให้ยา ตาย 10/40 = 25% — ต่างกันนิดเดียว บังเอิญได้ไหม?
ตาราง 2: ยา A ตาย 0/5 = 0% — ดูดีมากแต่มีแค่ 5 คน เชื่อได้แค่ไหน? → ต้องใช้สถิติ (CI, hypothesis test) ตอบ

02 Conditional probability · Independence · Bayes — ย่อจักรวาลให้เหลือแค่ B

P(A | B) = “ความน่าจะเป็นของ A เมื่อรู้แล้วว่า B เกิด” — ตัดทุกอย่างนอก B ทิ้ง แล้วถามว่าในพื้นที่ที่เหลือ A กินไปกี่ส่วน

สูตรหลัก

P(A | B) = P(A ∩ B)P(B) P(A ∩ B) = P(A | B) P(B) = P(B | A) P(A) P(A | B) = P(B | A) P(A)P(B)
P(B)law of total probability = P(B|A)P(A) + P(B|Aᶜ)P(Aᶜ)
อิสระP(A ∩ B) = P(A)P(B) ⇔ P(B | A) = P(B)

ตัวอย่างอิสระในสไลด์: P(Sarah ใส่เสื้อขาว | หุ้น AIS ขึ้น) = P(Sarah ใส่เสื้อขาว) — รู้อันหนึ่งไม่ได้ช่วยเดาอีกอันเลย

03 Frequentist vs Bayesian — ความน่าจะเป็นคืออะไรกันแน่

Frequentistอัตราที่เกิดเมื่อทำซ้ำมาก ๆ

  • โยนเหรียญ: P(head) = θ, ประมาณด้วย θ = #heads / #tosses
  • θ เป็นค่าคงที่ที่เราไม่รู้ — ไม่มี “ความน่าจะเป็นของ θ”
  • วิชานี้เน้นแนวทางนี้เป็นหลัก (CI, hypothesis test)

Bayesianความไม่แน่นอนในความรู้ของเรา

  • พารามิเตอร์เองก็มีการแจกแจง เช่น θ ~ U(0.6, 1.0) (prior)
  • ใส่ความรู้เดิมได้ (มุมมอง subjective) แล้วอัปเดตด้วยข้อมูลที่เห็น → posterior
  • ใช้ใน MAP (หน้า Estimation) และ multi-armed bandit

04 Random variable · PMF / PDF / CDF — แปลงผลลัพธ์เป็นตัวเลข

ตัวแปรสุ่ม (RV) คือฟังก์ชันที่ให้ค่าตัวเลขกับแต่ละผลลัพธ์ เช่น เหตุการณ์ A → 100 (Pr 0.5), B → 150 (Pr 0.3), C → 200 (Pr 0.2) · ถ้าค่าที่เป็นไปได้นับได้ใช้ PMF ถ้าต่อเนื่อง (เวลาเริ่มคลาส 9:00–12:00) ใช้ PDF และทั้งสองแบบมี CDF

DiscretePMF pX(x) = P(X = x)

  • Σ pX(x) = 1
  • เป็นความน่าจะเป็นจริง ๆ เช่น pX(5) = P(X = 5) = 0.5

ContinuousPDF fX(x)

  • ∫ fX(x) dx = 1, P(a ≤ X ≤ b) = ∫ab fX(x) dx
  • ไม่ใช่ความน่าจะเป็น (เกิน 1 ได้) และ P(X = x₀) = 0 ทุกจุด

ทั้งคู่CDF FX(x) = P(X ≤ x)

  • F(x) = ∫−∞x f(t) dt และ f(x) = dF/dx
  • P(a < X ≤ b) = F(b) − F(a) · ไม่ลด · จาก 0 ไป 1

Quantile: xq คือค่าที่ P(X ≤ xq) = q — median คือ q = 0.5, quartile q₁, q₂, q₃ ที่ 0.25/0.5/0.75, decile d₁…d₉ (เช่น P(X ≤ d₄) = 0.4), percentile p₁…p₉₉ · อ่านจาก CDF ในแนวนอน (เส้นสีส้ม)

05 Joint & marginal distribution — สองตัวแปรพร้อมกัน

Joint fX,Y(x, y) บอกความน่าจะเป็นที่ทั้งคู่เกิดพร้อมกัน · Marginal ได้จากการรวม (integrate) ตัวแปรอีกตัวทิ้ง · ถ้าอิสระ joint = ผลคูณของ marginal ทุกช่อง

P(A) = ∬A fX,Y(x, y) dx dy fX(x) = ∫ fX,Y(x, y) dy fY(y) = ∫ fX,Y(x, y) dx อิสระ ⇔ fX,Y = fX fY

ลองแก้น้ำหนักในตารางเอง (ไม่ต้องรวมเป็น 1 — หน้านี้ normalize ให้) แบบ discrete: ∫ กลายเป็น Σ — marginal คือผลรวมแถว / คอลัมน์

06 ผลบวกของตัวแปรสุ่ม — PDF ของ Z = X + Y คือ convolution

ถ้า X, Y อิสระ โอกาสที่ Z = z คือรวมทุกวิธีที่ X = x และ Y = z − x — เป็นสูตร convolution เดียวกับ part Signal ทุกตัวอักษร (พลิก → เลื่อน → คูณ → รวม)

fX+Y(z) = (fX ∗ fY)(z) = ∫−∞∞ fX(x) fY(z − x) dx discrete: pZ(z) = Σx pX(x) pY(z − x)

07 Expected value & variance — ค่ากลาง และความกระจาย

นิยาม

E[X] = μ = ∫ x f(x) dx E[g(X)] = ∫ g(x) f(x) dx E[X | A] = ∫ x f(x | A) dx
Var(X) = σ² = E[(X − μ)²] = E[X²] − (E[X])² σ = √Var(X)
Expected valueVariance
E[c] = cVar(c) = 0
E[aX + b] = aE[X] + bVar(aX + b) = a² Var(X) (b เลื่อนเฉย ๆ ไม่เปลี่ยนความกว้าง)
E[X + Y] = E[X] + E[Y] (เสมอ แม้ไม่อิสระ)Var(X + Y) = Var(X) + Var(Y) + 2Cov(X, Y)
E[X − Y] = E[X] − E[Y]Var(X − Y) = Var(X) + Var(Y) − 2Cov(X, Y) (ถ้าอิสระ: บวก ไม่ใช่ลบ!)
E[XY] = E[X]E[Y] ถ้าอิสระVar(X + Y) = Var(X) + Var(Y) ถ้าอิสระ
กับดักที่ออกบ่อย: Var(2X) = 4Var(X) แต่ Var(X + X') = 2Var(X) เมื่อ X, X' อิสระและแจกแจงเหมือนกัน — “X บวกตัวเอง” กับ “บวกสำเนาอิสระ” ไม่เท่ากัน (เพราะ Cov(X, X) = Var(X)) นี่คือเหตุผลที่ค่าเฉลี่ยของ n ตัวอย่างมีความแปรปรวน σ²/n

ลองดูด้วยลูกเต๋า X (1–6): เทียบ Y = aX + b กับ X₁ + X₂

ตัวอย่าง · ลอตเตอรี่ P(ถูก) = 10−20 ได้ 1030 · ไม่ถูก เสีย 10

E = 1030·10−20 + (1 − 10−20)(−10) ≈ 1010 − 10 — ค่าคาดหมายสูงมากแต่โอกาสถูกแทบเป็นศูนย์ E คือค่าเฉลี่ยถ่วงน้ำหนัก ไม่ได้บอกว่าอะไร “มักจะเกิด” และคนเราประเมินความน่าจะเป็นที่ปลายสุดได้แย่มาก

08 Covariance & correlation — วัดความสัมพันธ์เชิงเส้น

Cov(X₁, X₂) = E[(X₁ − μ₁)(X₂ − μ₂)] = E[X₁X₂] − μ₁μ₂ ρ = Cov(X, Y)√Var(X) √Var(Y) ∈ [−1, 1]
Cov(X,X)= Var(X)
Cov(aX+b, cY+d)= ac Cov(X, Y)
Cov(X, Y+Z)= Cov(X,Y) + Cov(X,Z)
Σcovariance matrix: Σij = Cov(Xi, Xj)

Correlation note

  • วัดเฉพาะความสัมพันธ์เชิงเส้น — Anscombe ทั้ง 4 ชุดมี ρ = 0.816 เท่ากันหมดแต่หน้าตาต่างกันสิ้นเชิง
  • Uncorrelated ⇏ independent (ลองชุด Y = X²: ρ ≈ 0 แต่ Y ขึ้นกับ X ชัดเจน) · แต่ independent ⇒ uncorrelated เสมอ
  • Correlation ⇏ causation (spurious correlations)

Covariance matrix

  • สมมาตร Σ = Σᵀ และ positive semi-definite
  • Σ เป็น diagonal ⇒ ทุกคู่ uncorrelated (และเป็นอิสระถ้า jointly Gaussian)
  • positive definite ⇒ invertible (ยกเว้นมี linear combination ของ RV ที่ variance = 0)
