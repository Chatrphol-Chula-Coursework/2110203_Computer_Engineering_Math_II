สูตรมาจากไหน why, not just what

หน้านี้ไม่มีสูตรใหม่ — เอาสูตรที่ใช้บ่อยที่สุดใน part สถิติมาไล่ “ที่มา” ทีละบรรทัด กด ขั้นถัดไป (หรือคลิกบรรทัดไหนก็ได้) แล้วรูปทางซ้ายจะเปลี่ยนตามบรรทัดที่กำลังอ่าน ทุกรูปคำนวณจากตัวเลขจริงในสไลด์

01 Bayes' rule — มาจากการ “ย่อจักรวาล” ให้เหลือแค่ B

  1. กล่องสี่เหลี่ยมพื้นที่ 1 = ผลลัพธ์ทั้งหมด
    ความน่าจะเป็น = พื้นที่
  2. แบ่งตาม A: กว้าง P(A) = 0.3
    ซ้าย = A, ขวา = Aᶜ
  3. ใน A, เหตุการณ์ B กินสูง P(B|A) = 0.8 → พื้นที่ P(A∩B) = P(B|A)·P(A) = 0.24
    กว้าง × สูง = กฎการคูณ
  4. ใน Aᶜ, B กินสูง 0.2 → 0.7 × 0.2 = 0.14 · รวม P(B) = 0.24 + 0.14 = 0.38
    law of total probability = รวมทุกชิ้นของ B
  5. รู้ว่า B เกิด → ทิ้งทุกอย่างนอก B · P(A|B) = ชิ้นแดงB ทั้งหมด = 0.240.38 = 0.63
    นี่คือ P(A|B) = P(A∩B)/P(B)
  6. P(A|B) = P(B|A) P(A)P(B)
    แทนชิ้นแดงด้วยขั้นที่ 3 → ได้ Bayes

02 ทำไม Var(X̄) = σ²/n — บวกแล้วกว้างขึ้น หารแล้วแคบลง

  1. ทอยลูกเต๋า 1 ลูก: μ = 3.5 , σ² = 35/12 ≈ 2.92
    เท่ากันทุกหน้า
  2. S₂ = X₁ + X₂ → Var = σ² + σ² = 2σ²
    อิสระ → Cov = 0 → variance บวกกันตรง ๆ · รูปเป็นสามเหลี่ยม (convolution)
  3. S₁₀ = X₁ + ⋯ + X₁₀ → Var = 10σ² → SD = √10 σ
    กว้างขึ้นแค่ √n เท่า ไม่ใช่ n เท่า — ค่าสูงต่ำหักล้างกัน
  4. X̄ = Sn/n → Var(X̄) = Var(Sn)/n² = nσ²/n² = σ²/n
    Var(aX) = a²Var(X) กับ a = 1/n · วาดทุก n บนแกนเดียวกัน: n ยิ่งมาก ยิ่งแคบ
  5. รูปร่างของ X̄ กลายเป็นระฆัง (เส้นแดง = N(3.5, σ²/10))
    นี่คือ CLT — ทั้งที่ลูกเต๋าเดี่ยว ๆ แบนราบ

03 Standardize: ทำไมหาร SD แล้วเปิดตาราง Φ ได้ — เหรียญ 100 ครั้ง P(S > 55)

  1. S ≈ N(50, 5²) — อยากรู้พื้นที่ขวาของ 55
    E = np = 50, SD = √(np(1−p)) = 5
  2. ลบค่าเฉลี่ย: S − 50 → ระฆังย้ายมาอยู่ที่ 0 · จุด 55 → 5
    เลื่อนทั้งรูป พื้นที่ไม่เปลี่ยน
  3. หารด้วย SD: (S − 50)/5 → ความกว้างเป็น 1 · จุด 5 → 1
    ยืด/หดแกน x พร้อมกันทั้งรูป พื้นที่ส่วนแรเงายังเป็นสัดส่วนเดิม
  4. ได้ Z ~ N(0,1) ทุกครั้ง → P(S > 55) = P(Z > 1) = 0.159
    ตาราง Φ มีแค่ N(0,1) ตัวเดียวพอสำหรับทุก Normal

04 95% CI = p̂ ± 1/√n มาจากไหน — กลับด้านระยะทาง + กรณีแย่สุด

  1. CLT: p̂ ~ N(p₀, σ²/n) — 95% ของ p̂ ตกใน p₀ ± 2σp̂
    เราไม่รู้ p₀ แต่รู้ว่า p̂ ไม่ค่อยไปไกลจากมัน
  2. “p̂ ห่าง p₀ ไม่เกิน 2σ” เหมือนกับ “p₀ ห่าง p̂ ไม่เกิน 2σ” → ช่วง p̂ ± 2σ คร่อม p₀
    ระยะทางสมมาตร · จุดฟ้า = p̂ จากโพลต่าง ๆ — ตัวที่ตกนอกแถบ ช่วงของมันพลาด p₀ (แดง)
  3. แต่ σ² = p₀(1 − p₀) ขึ้นกับ p₀ ที่ไม่รู้ → ใช้ค่าที่ใหญ่สุด
    p(1−p) เป็นพาราโบลา สูงสุด 1/4 ที่ p = 0.5
  4. σ ≤ 1/2 ⇒ 2σp̂ = 2σ/√n ≤ 2·(1/2)/√n = 1/√n
    ช่วงกว้างพอแน่นอนไม่ว่า p₀ เป็นเท่าไร (conservative)
  5. n = 400 → ±0.05 · n = 100 → ±0.10 · n = 10,000 → ±0.01
    แคบลงครึ่งหนึ่ง ต้องเพิ่ม n สี่เท่า

05 MLE: ทำไมตั้งอนุพันธ์ = 0 แล้วได้ k/n — Maxwell 55/100

  1. L(p) = P(ข้อมูล | p) = C(100,55)·p⁵⁵(1−p)⁴⁵
    ลองทุก p แล้วดูว่า p ไหนทำให้ “55 จาก 100” น่าเกิดที่สุด → ยอดเขาคือคำตอบ
  2. ln L = 55 ln p + 45 ln(1−p) + ค่าคงที่
    ln เพิ่มเสมอ → ยอดเขาอยู่ที่ p เดิม แต่ผลคูณกลายเป็นผลบวก หาอนุพันธ์ง่าย
  3. ที่ยอดเขา เส้นสัมผัสแบนราบ: ซ้ายของยอดชันขึ้น (+) ขวาชันลง (−)
    เส้นแดง = ความชัน ณ p ต่าง ๆ — ที่ยอด slope = 0
  4. d ln L/dp = 55/p − 45/(1−p) = 0 ⇔ 55/p = 45/(1−p)
    “แรงดึงจากความสำเร็จ” เท่ากับ “แรงดึงจากความล้มเหลว” → จุดตัดสองเส้น
  5. 55(1−p) = 45p ⇒ p̂ = 55/100 = 0.55
    ทั่วไป p̂ = k/n — สัญชาตญาณถูกต้อง

06 t = (x̄ − μ₀)/(s/√n) — “ห่างกี่เท่าของ noise”

  1. GCC: 12.5, 13.1, 12.8, 13.5, 12.9 · x̄ = 12.96 · สมมติ H₀: μ₀ = 12.5
    signal = x̄ − μ₀ = 0.46 วินาที — มากหรือน้อย?
  2. noise ของ “ค่าเดี่ยว” = s = 0.371
    ข้อมูลแต่ละตัวแกว่งประมาณเท่านี้ (แถบเทา = x̄ ± s)
  3. noise ของ “ค่าเฉลี่ย” = s/√n = 0.371/√5 = 0.166
    ค่าเฉลี่ยแกว่งน้อยกว่าค่าเดี่ยว √n เท่า (สูตร 02) — แถบเขียว
  4. t = signal/noise = 0.46/0.166 = 2.77 — ห่าง 2.77 เท่าของ SE
  5. เทียบกับ t(4) (ไม่ใช่ N(0,1)) เพราะ s เองก็ประมาณมาจากข้อมูล 5 ตัว → หางหนากว่า
    two-sided critical t₀.₀₂₅,₄ = 2.776 → 2.77 เฉียดเส้นพอดี (p ≈ 0.05)

07 SE ของผลต่างสองกลุ่ม — ทำไมลบกันแต่ variance บวกกัน

  1. x̄ (GCC) ~ N(μ₁, σ²/5) , ȳ (Clang) ~ N(μ₂, σ²/5)
    แต่ละค่าเฉลี่ยมีความไม่แน่นอนของตัวเอง
  2. x̄ − ȳ: Var = Var(x̄) + Var(−ȳ) = σ²/n + σ²/m
    Var(−Y) = (−1)²Var(Y) = Var(Y) — ความไม่แน่นอนสองแหล่งสะสมไม่ได้หักล้าง → ระฆังม่วงกว้างกว่าทั้งสองใบ
  3. ไม่รู้ σ² → รวม s² สองกลุ่มแบบถ่วงน้ำหนัก: sp² = 4(0.138) + 4(0.075)8 = 0.1065
    pooled: ใช้ข้อมูลทั้ง 10 ตัวประมาณ σ² ตัวเดียว (assume σ เท่ากัน) · น้ำหนัก = n − 1
  4. SE = sp√(1/5 + 1/5) = 0.206 → t = (12.96 − 12.10)/0.206 = 4.17
    df = n + m − 2 = 8 (เสีย 1 ต่อกลุ่มจากการประมาณค่าเฉลี่ย)

08 Two-proportion z — Bernoulli → CLT → ผลต่าง → pooled

  1. แต่ละคน = Bernoulli: 1 ด้วย p , mean p , Var = p(1−p)
    ยา A: รอด = 1 · E[X²] − E[X]² = p − p²
  2. p̂ = ค่าเฉลี่ยของ n คน → CLT: p̂ ≈ N(p, p(1−p)/n)
    สัดส่วน = ค่าเฉลี่ยของ 0/1 — สูตร 02 ใช้ได้ทันที
  3. p̂₁ − p̂₂: Var = p₁(1−p₁)/n₁ + p₂(1−p₂)/n₂
    ผลต่าง → variance บวกกัน (สูตร 07)
  4. ใต้ H₀: p₁ = p₂ = p → ประมาณ p ตัวเดียวจากทุกคน: p̂ = (31+30)/(40+40) = 0.7625
    pooled — ถ้าสมมติว่าเท่ากัน ก็ใช้ข้อมูลรวมประมาณ
  5. z = 0.775 − 0.75√(0.7625·0.2375·(1/40+1/40)) = 0.0250.0952 = 0.26
    ห่างแค่ 0.26 SE → แทบอยู่กลางระฆัง ไม่ significant

09 Sample size n = 2((zα+zβ)σ/MDE)² — เส้นเดียวต้องตัดสองระฆังพอดี

  1. ผลต่างที่วัดได้ ~ N(0, SE²) ถ้า H₀ จริง · ~ N(MDE, SE²) ถ้า effect = MDE
    SE = σ√(1/n + 1/n) = σ√(2/n) (สูตร 07)
  2. เส้น critical ต้องอยู่ห่าง 0 ไป zα·SE → พื้นที่ขวา = α
    คุม false positive
  3. เส้นเดียวกันต้องอยู่ซ้ายของ MDE zβ·SE → พื้นที่ซ้ายของระฆัง HA = β
    คุม false negative (power = 1 − β)
  4. ระยะ 0 → MDE = zαSE + zβSE ⇒ MDE = (zα + zβ)·σ√(2/n)
    สองช่วงต่อกันพอดี
  5. แก้หา n: n = 2((zα+zβ)σ/MDE)² → p = 10% (σ² = .09), MDE .01 → 11,128
    MDE เล็กลงครึ่ง → n × 4 · σ ใหญ่ → n มาก

10 Inverse transform: ทำไม F⁻¹(U) ได้การแจกแจง F — Exponential(1)

  1. U ~ U(0,1): จุดบนแกนตั้งกระจายเท่ากันทุกช่วง
    คอมพิวเตอร์สุ่มได้แค่นี้
  2. ส่งแต่ละ u ผ่านเส้น CDF ลงแกนนอน: x = F⁻¹(u)
    ช่วงที่ CDF ชัน = u ช่วงยาวถูกบีบลงช่วง x สั้น → จุดหนาแน่น (pdf สูง)
  3. P(X ≤ x) = P(F⁻¹(U) ≤ x) = P(U ≤ F(x))
    F เพิ่มเสมอ → “x ไม่เกิน” เท่ากับ “u ไม่เกิน F(x)” (แถบเขียว)
  4. U uniform → P(U ≤ F(x)) = F(x) ⇒ X มี CDF = F
    histogram ของ x ทับ pdf e⁻ˣ พอดี
