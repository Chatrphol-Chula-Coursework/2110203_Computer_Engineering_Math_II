1.1 Pearson correlation ของข้อมูลนี้ — 1 คะแนน

โจทย์. What is the Pearson correlation coefficient of this data? (รูป: จุดเรียงเป็นเส้นตรงลาดลงเส้นเดียว)

  1. จุดทุกจุดอยู่บนเส้นตรง Y = a + bX เดียวกัน โดย b < 0 (ลาดลง)
    อ่านจากรูป: ไม่มีจุดไหนกระจายออกจากเส้น
  2. Cov(X, Y) = Cov(X, a + bX) = b·Var(X)
    Cov(X, a + bX) = b Cov(X, X) และ Cov(X, X) = Var(X)
  3. Var(Y) = b²Var(X) ⇒ √Var(Y) = |b|√Var(X)
    Var(aX + b) = a²Var(X)
  4. ρ = b Var(X)√Var(X) · |b|√Var(X) = b|b| = −1
    ρ บอกแค่ว่าจุดเกาะเส้นตรงแค่ไหนและทิศทาง — ไม่ขึ้นกับความชัน (ลาดน้อยหรือมากก็ −1)

ตอบ ρ = −1 · กับดัก: อย่าตอบเป็นค่าความชัน หรือ “ประมาณ −0.3” เพราะเส้นดูลาดน้อย

1.3 โยนเหรียญ 30 ครั้งได้หัว 21 → p̂ และ 95% CI — 1 คะแนน

  1. p̂MLE = k/n = 21/30 = 0.7
    MLE ของ Bernoulli/Binomial (Lecture 1B) · ln L = 21 ln p + 9 ln(1−p) → 21/p = 9/(1−p)
  2. CLT: p̂ ≈ N(p, p(1−p)/n) → 95% CI = p̂ ± 2σp̂
    n = 30 พอสำหรับ CLT (np̂ = 21, n(1−p̂) = 9 ≥ 5)
  3. แบบ worst case (สไลด์): σ ≤ 1/2 → 2σp̂ ≤ 1/√n = 1/√30 = 0.1826
    p(1−p) ≤ 1/4
  4. 95% CI = 0.7 ± 0.1826 = [0.517, 0.883]
    คำตอบตามสูตรในสไลด์
  5. แบบ plug-in: 0.7 ± 1.96√(0.7·0.3/30) = 0.7 ± 0.164 = [0.536, 0.864]
    แคบกว่าเพราะ p̂ = 0.7 ห่างจาก 0.5 — ตอบแบบไหนก็ได้ถ้าบอกว่าใช้สูตรอะไร

ทั้งสองช่วงไม่คร่อม 0.5 → มีหลักฐานว่าเหรียญเอียงไปทางหัว (เทียบเท่า two-sided test ที่ α = 0.05)

1.4 AI ตรวจมะเร็งปอด บอกว่าเป็น → เป็นจริงกี่ % — 1 คะแนน

โจทย์. โอกาสเป็นมะเร็งปอด 1 ใน 16 · AI มี significance 0.01 และ power 0.8 · ถ้า AI บอกว่าเป็นมะเร็ง ความน่าจะเป็นที่เป็นจริงคือ?

  1. P(C) = 1/16 = 0.0625 , P(Cᶜ) = 15/16 = 0.9375
    prior (base rate)
  2. power = P(AI + | C) = 0.8
    power = โอกาสจับได้เมื่อมีของจริง (1 − β)
  3. significance α = P(AI + | Cᶜ) = 0.01
    α = false positive rate — ปฏิเสธ H₀ (“ไม่เป็น”) ทั้งที่ H₀ จริง
  4. P(AI +) = 0.8(0.0625) + 0.01(0.9375) = 0.05 + 0.009375 = 0.059375
    law of total probability
  5. P(C | AI +) = 0.050.059375 = 1619 ≈ 0.842
    Bayes' rule
ลอง prior 1 ใน 1,000: แม้ AI แม่นแบบเดิม ผลบวกส่วนใหญ่กลับเป็น false positive — base rate สำคัญมาก

    “smarter” → one-sided (ด้านขวา)
  2. ข้อมูล n = 10 (เพื่อน 9 + ตัวเอง 1): 116, 72, 108, 107, 116, 117, 73, 106, 92, 93
    อย่าลืมรวมตัวเอง — “you and your friends (as a group)”
  3. Σx = 1000 ⇒ x̄ = 100
    116+72+108+107+116+117+73+106+92+93 = 1000
  4. σ = 15 รู้ค่า ⇒ ใช้ z-test: z = x̄ − μ₀σ/√n = 100 − 10015/√10 = 0
    รู้ σ ของประชากร → z ไม่ใช่ t
  5. p-value = P(Z ≥ 0) = 0.5

2 โพลก่อนเลือกตั้ง US 2024 ลำเอียงไหม — 5 คะแนน

โจทย์. Harris 72,350,340 · Trump 75,492,424 · โพล 1/2/3 ให้ Trump 53.333% (n = 150), 49.000% (n = 500), 53.500% (n = 1000) · ใช้ α = 0.1

ค่าจริงของประชากร (รู้แน่นอนหลังเลือกตั้ง)

  1. p₀ = 75,492,42472,350,340 + 75,492,424 = 75,492,424147,842,764 = 0.51063
    คิดเฉพาะสองตัวเลือก (Bernoulli)

2.1Hypothesis

สำหรับแต่ละโพล i: H₀: pi = p₀ = 0.51063 (โพลไม่ลำเอียง — สุ่มมาจากประชากรจริง) · HA: pi ≠ p₀ (ลำเอียง)

2.2Two-sided

“ลำเอียง” เกิดได้ทั้งเข้าข้าง Trump หรือ Harris (Trump อ้างว่าไม่แฟร์ — ไม่ได้ระบุทิศ) → two-sided

2.3One-sample z-test for proportion

n ใหญ่ (np₀, n(1−p₀) ≥ 5) → CLT: p̂ ≈ N(p₀, p₀(1−p₀)/n) และใต้ H₀ รู้ σ = √(p₀(1−p₀)) แน่นอน → z-test ไม่ใช่ t-test

2.4Critical values

α = 0.1 two-sided → แต่ละหาง 0.05 → z = ±1.645 (ตารางแถว ∞ คอลัมน์ 0.05)

2.5 · คำนวณทีละโพล

  1. p₀(1 − p₀) = 0.51063 × 0.48937 = 0.24989
    variance ของ Bernoulli ใต้ H₀
  2. Poll 1: SE = √(0.24989/150) = 0.04082 , z = (0.53333 − 0.51063)/0.04082 = 0.556
    |z| < 1.645 → ไม่ปฏิเสธ H₀ (p-value 0.578)
  3. Poll 2: SE = √(0.24989/500) = 0.02236 , z = (0.49 − 0.51063)/0.02236 = −0.923
    |z| < 1.645 → ไม่ปฏิเสธ (p-value 0.356) — ถึงจะทาย Harris ชนะ ก็ยังอยู่ในความคลาดเคลื่อนปกติ
  4. Poll 3: SE = √(0.24989/1000) = 0.01581 , z = (0.535 − 0.51063)/0.01581 = 1.542
    |z| = 1.542 < 1.645 → ไม่ปฏิเสธ (p-value 0.123) — ใกล้เส้นที่สุด
  5. ไม่มีโพลไหนลำเอียงอย่างมีนัยสำคัญที่ α = 0.1 → คำอ้างของ Trump ว่าโพล “rigged” ไม่มีหลักฐานรองรับ
    ความต่างจากผลจริงอธิบายได้ด้วย sampling error ล้วน ๆ

3 Taste like Chocolate — เลือกรสไหนดี — 5 คะแนน

Flavor12345678910

3.1Hypothesis (แต่ละรส i)

H₀: μi = 8.5 (ไม่ดีกว่ารสปกติ) · HA: μi > 8.5 (ดีกว่า)

3.2One-sided

สนใจแค่ว่า “อร่อยกว่า” รสเดิมหรือไม่ — รสที่แย่กว่าไม่เอาอยู่แล้ว

3.3One-sample t-test

n = 5 คน, ไม่รู้ σ ของประชากร → ใช้ s แทน → t-distribution, df = n − 1 = 4

3.4 · ปัญหา multiple comparisons

  1. ทดสอบ 10 รสพร้อมกัน แต่ละอันมีโอกาส false positive α
    ยิ่งทดสอบหลายอัน ยิ่งมีโอกาส “ฟลุ๊ก” เจอรสที่ดูดีทั้งที่ไม่ได้ดีจริง
  2. P(มี false positive อย่างน้อย 1) = 1 − (1 − 0.05)10 ≈ 0.40
    family-wise error rate (FWER) พุ่งจาก 5% เป็น 40%
  3. Bonferroni: αeach = α/m = 0.05/10 = 0.005
    ทำให้ FWER ≤ 0.05
  4. critical value: t0.005, 4 = 4.604
    ในตารางข้อสอบ ค่า 4.604 อยู่ช่องที่เขียนว่า “0.001” (ป้ายเลื่อน) — ถ้าไม่แก้ multiple testing จะใช้ t0.05,4 = 2.132

คำนวณ t ของรสที่ “มีลุ้น” (mean > 8.5 มีแค่รส 10)

  1. รส 10: 9, 10, 9, 9, 10 → x̄ = 9.4
  2. s² = [(−0.4)² + 0.6² + (−0.4)² + (−0.4)² + 0.6²]/4 = 1.2/4 = 0.3 → s = 0.5477
    หารด้วย n − 1
  3. t = 9.4 − 8.50.5477/√5 = 0.90.2449 = 3.674 , p-value (one-sided) = 0.0107
    df = 4
  4. 3.674 > 2.132 (ไม่แก้) แต่ 3.674 < 4.604 (Bonferroni)
    ผ่านถ้าทดสอบรสเดียว แต่ไม่ผ่านหลังแก้ multiple comparisons
  5. รส 1–9: x̄ ≤ 8.4 < 8.5 → t < 0 → ไม่มีทางปฏิเสธ H₀
    ค่า t อยู่ในกราฟด้านล่าง

3.5เลือก 1 รส → รส 10

เป็นรสเดียวที่ค่าเฉลี่ยเกิน 8.5 (9.4) และได้ t สูงสุด (p = 0.011) แต่หลัง Bonferroni ยังไม่ significant → ควรรายงานว่า “น่าจะดีที่สุด แต่หลักฐานยังไม่พอจะยืนยันว่าดีกว่ารสเดิม” แนะนำทดสอบรส 10 ซ้ำกับผู้ทดลองชุดใหม่ (confirmatory test ที่ทดสอบรสเดียว ใช้ α = 0.05 ได้เต็ม) หรือเพิ่ม n

3.6เลือก 3 รส → 10, 6, 9

หลังรส 10 ไม่มีรสไหนดีกว่า 8.5 — รส 6, 7, 8, 9 ค่าเฉลี่ย 8.4 เท่ากัน และไม่ต่างจาก 8.5 อย่างมีนัยสำคัญ (t ≈ −0.25 ถึง −0.41) จึงเลือกจากความสม่ำเสมอ: รส 6 และ 9 มี s = 0.548 ขณะที่รส 7, 8 มี s = 0.894 เพราะถูกดึงด้วยคะแนน 10 จากคนเดียว (B ให้รส 7, D ให้รส 8) → รส 6, 9 ถูกปากคนส่วนใหญ่กว่า · อีกเหตุผล: ไม่ควรเลือกจากค่าเฉลี่ยอย่างเดียว

4 Sunflowium — วัสดุ A หรือ B ระบายความร้อนดีกว่า — 5 คะแนน

ข้อมูล (°C). A: 75, 76, 77, 78, 79, 80, 81, 82, 78, 79 · B: 73, 74, 75, 76, 77, 78, 79, 80, 76, 77 · เป้าหมาย: ต่ำกว่า 80°C

4.1Hypothesis

H₀: μA = μB (ไม่ต่างกัน) · HA: μA ≠ μB

4.2Two-sample t-test · two-sided

สองกลุ่มอิสระ (คนละวัสดุ ไม่ได้จับคู่), ไม่รู้ σ, n = 10 ต่อกลุ่ม → independent two-sample t-test · ถามว่า “อันไหนดีกว่า” โดยไม่รู้ทิศล่วงหน้า → two-sided

4.3 · คำนวณ (α = 0.05)

  1. x̄A = 785/10 = 78.5 , x̄B = 765/10 = 76.5 , ผลต่าง = 2.0
  2. Σ(x − x̄A)² = 12.25+6.25+2.25+0.25+0.25+2.25+6.25+12.25+0.25+0.25 = 42.5 → sA² = 42.5/9 = 4.722
    B คือ A เลื่อนลง 2 ทุกตัว → sB² = 4.722 เท่ากัน
  3. pooled: sp² = 9(4.722) + 9(4.722)18 = 4.722 , SE = sp√(1/10 + 1/10) = √(4.722 × 0.2) = 0.9718
    variance เท่ากันพอดี → pooled กับ Welch ได้ผลเดียวกัน
  4. t = 2.0/0.9718 = 2.058 , df = 10 + 10 − 2 = 18
  5. critical (two-sided, α = 0.05): t0.025, 18 = 2.101 → |2.058| < 2.101
    ในตารางข้อสอบอยู่ช่อง “0.01” ที่ป้ายผิด · p-value = 0.054
  6. ไม่ปฏิเสธ H₀ — ผลยัง inconclusive (เกือบถึงเกณฑ์ p = 0.054)
    ถ้าตั้ง one-sided μA > μB ตั้งแต่แรก (crit 1.734) จะ significant — แต่ห้ามเปลี่ยนเป็น one-sided หลังเห็นข้อมูล (p-hacking)

4.4ทำอะไรต่อ

  • เพิ่มจำนวนการวัด — power analysis: ต่างกัน 2°C, s ≈ 2.17 → ต้อง n ≈ 19 ต่อกลุ่มที่ power 0.8
  • Paired design — วัด A กับ B บนอุปกรณ์/โหลด/อุณหภูมิห้องเดียวกันเป็นคู่ ลด variance จากสภาพแวดล้อม
  • ทดสอบตรงเป้าหมาย — one-sample t-test ว่าแต่ละวัสดุ μ < 80 หรือไม่: A: t = −2.18 (p = 0.028), B: t = −5.09 (p = 0.0003) → ทั้งคู่ต่ำกว่า 80 อย่างมีนัยสำคัญ
  • เช็ก assumption (normality, ความอิสระของการวัดต่อเนื่อง)

4.5สรุป

B มีแนวโน้มดีกว่า: เย็นกว่าเฉลี่ย 2°C ทุกค่าเลื่อนลงทั้งชุด และทุกค่าไม่เกิน 80°C ขณะที่ A มี 2 ครั้ง (81, 82) เกินเกณฑ์ — แต่ทางสถิติความต่างของค่าเฉลี่ยยังไม่ถึงระดับ 0.05 จึงควรเก็บข้อมูลเพิ่มก่อนตัดสินใจขั้นสุดท้าย

5 The Great Gambit — MLE ของเหรียญที่มองไม่เห็น — 5 คะแนน

โจทย์. โยนเหรียญ: หัว → ลูกเต๋า A (เท่ากันทุกหน้า 1/6), ก้อย → ลูกเต๋า B (หน้าคี่ 1/9, หน้าคู่ 2/9) · เห็นแต่ลูกเต๋า 22 รอบ: หน้า 1–6 ออก 3, 4, 2, 5, 4, 4 ครั้ง · หา MLE ของ θ = P(หัว)

  1. P(หน้า k) = θ·PA(k) + (1 − θ)·PB(k)
    law of total probability — เราไม่เห็นเหรียญ จึงต้องรวมทั้งสองกรณี (mixture)
  2. หน้าคี่: a = θ6 + 1 − θ9 = θ + 218    หน้าคู่: b = θ6 + 2(1 − θ)9 = 4 − θ18
    หา ค.ร.น. 18 · เช็ก: 3a + 3b = 18/18 = 1 ✓
  3. ออกหน้าคี่ (1, 3, 5) = 3 + 2 + 4 = 9 ครั้ง , หน้าคู่ (2, 4, 6) = 4 + 5 + 4 = 13 ครั้ง
    หน้าในกลุ่มเดียวกันมีความน่าจะเป็นเท่ากัน จึงรวมนับได้
  4. L(θ) = a9 b13 = (θ + 2)9(4 − θ)131822
    22 รอบอิสระ → likelihood = ผลคูณ
  5. ln L = 9 ln(θ + 2) + 13 ln(4 − θ) − 22 ln 18
    log-likelihood
  6. ddθ ln L = 9θ + 2 − 134 − θ = 0
    อนุพันธ์ของ ln(4 − θ) = −1/(4 − θ)
  7. 9(4 − θ) = 13(θ + 2) ⇒ 36 − 9θ = 13θ + 26 ⇒ 22θ = 10
    คูณไขว้
  8. θ̂MLE = 5/11 ≈ 0.4545
    อยู่ใน [0, 1] ✓ และอนุพันธ์อันดับสอง −9/(θ+2)² − 13/(4−θ)² < 0 → เป็นจุดสูงสุด ✓
ทางลัด: P(คี่) = 3a = (θ + 2)/6 ตั้งให้เท่ากับสัดส่วนที่เห็น 9/22 → θ = 6·9/22 − 2 = 5/11 (MLE ของ Bernoulli “คี่/คู่” แล้วแปลงกลับ) · ถ้าได้ θ̂ นอก [0, 1] ให้ตัดที่ขอบ

กลยุทธ์ที่ตามมา: ด้วย θ̂ = 5/11 → P(คู่) = 3b = (4 − 5/11)/6 = 13/22 ต่อ 3 หน้า = 0.197 ต่อหน้า vs หน้าคี่ 0.136 → ควรแทงหน้าคู่ (2, 4, หรือ 6)

6 Boss Hamtaro — ออกแบบ A/B test — 10 คะแนน

สถานการณ์. คนดูคอร์ส 1% กลายเป็น downline (กำไร 10,000 บาท) อีก 99% ได้ 10 บาท · Koushi เสนอเพิ่มวิดีโอ (B) → ค่า bandwidth ทำให้คนที่ไม่เป็น downline เหลือ 5 บาท แต่อ้างว่าคนเป็น downline มากขึ้น

6.1ทำไมไม่ทำแบบ “ปล่อย B อย่างเดียวช่วงหนึ่งแล้วดูผล”

  • ไม่มี control พร้อมกัน — เทียบ “ก่อน vs หลัง” ปนผลของเวลา: ฤดูกาล วันหยุด กระแสโซเชียล ข่าวตำรวจไล่จับ จำนวน/ประเภทคนที่เข้ามาเปลี่ยนไปเอง (time confounding)
  • Selection bias — คนที่เข้ามาช่วงหลังอาจเป็นคนที่ถูกชวนจาก downline เดิม (โอกาสเป็น downline สูงกว่าอยู่แล้ว)
  • Novelty effect — เนื้อหาใหม่อาจได้ผลดีช่วงแรกแล้วจางลง
  • ถ้า B แย่จริง เสียรายได้ทั้งหมดในช่วงทดลอง ไม่มีกลุ่มเดิมรองรับ → A/B test แบ่งความเสี่ยงและให้ causal effect

6.2 · Metric — กำไรเฉลี่ยต่อผู้ชม 1 คน (ไม่ใช่ conversion rate เฉย ๆ)

  1. E[กำไร/คน] = 10,000·p + c·(1 − p)
    p = อัตราการเป็น downline, c = กำไรจากคนที่ไม่เป็น downline
  2. A: 10,000(0.01) + 10(0.99) = 100 + 9.9 = 109.9 บาท/คน
    baseline
  3. B: 10,000 pB + 5(1 − pB) = 5 + 9,995 pB
    B เสียกำไรต่อคนทั่วไปครึ่งหนึ่ง
  4. B คุ้มเมื่อ 5 + 9,995 pB > 109.9 ⇔ pB > 1.0495%
    ต้องเพิ่ม conversion ≥ ~5% (relative) แค่ชดเชยค่า bandwidth
  5. Assumption: กำไรต่อ downline คงที่ 10,000 บาทเท่ากันทั้ง A และ B, ราคาคอร์สเท่าเดิม, วัด downline ได้ภายในระยะเวลาทดลอง
    ถ้า assumption นี้จริง ทดสอบ conversion rate กับเกณฑ์ 1.0495% ให้ผลเหมือนการทดสอบกำไรเฉลี่ย (และ variance ต่ำกว่าวัดเงินตรง ๆ)

6.3แบ่งกลุ่ม A/B

  • สุ่มที่ระดับผู้ใช้ (hash user ID) 50/50 ให้แต่ละคนเห็นเวอร์ชันเดียวตลอด (ไม่ใช่สุ่มต่อการเปิดดู)
  • รันพร้อมกันช่วงเวลาเดียวกัน → คุมผลของเวลา/ฤดูกาล
  • คุม: ราคา 99 บาท, ช่องทางที่มา (ads/โซเชียล), อุปกรณ์, ภาษา, คนที่เคยดูแล้ว (ตัดออก) · ตรวจ sample ratio mismatch
  • ถ้ากลัวเสียเงิน แบ่ง B น้อยกว่า (เช่น 10%) ได้แต่ต้องใช้เวลานานขึ้น

6.4การแจกแจงของ metric

  • แต่ละคน: downline หรือไม่ = Bernoulli(p)
  • จำนวน downline ใน n คน = Binomial(n, p)
  • สัดส่วน p̂ ≈ Normal(p, p(1−p)/n) ตาม CLT (n ใหญ่)
  • กำไรต่อคน = ตัวแปรสองค่า (10,000 หรือ c) — หางยาวมาก variance สูง จึงทดสอบผ่าน p แทน

6.5 · Stopping criterion — กำหนด sample size ล่วงหน้าด้วย power analysis

  1. H₀: pB ≤ p*   vs   HA: pB > p* , p* = 1.0495% (หรือเทียบ pA โดยตรง)
    one-sided: สนใจเฉพาะ B ดีกว่าจนคุ้ม
  2. n ต่อกลุ่ม ≈ (zα + zβ)² [p₁(1−p₁) + p₂(1−p₂)](p₂ − p₁)²
    two-proportion z-test, α = 0.05 (z = 1.645), power 0.8 (z = 0.842)
  3. ถ้าต้องการจับ p₂ = 1.2% (เพิ่ม 20%): n ≈ 6.18 × (0.0099 + 0.01186)/0.002² ≈ 33,600 คน/กลุ่ม
    ถ้าจะจับให้ได้แค่จุดคุ้มทุน 1.05% ต้องใช้ ~500,000 คน/กลุ่ม — effect เล็กต้องใช้ข้อมูลเยอะมาก
  4. กฎหยุด: เก็บจนครบ n ที่คำนวณไว้ (อย่างน้อย 1–2 สัปดาห์เต็มให้ครอบคลุมวันในสัปดาห์) แล้วค่อยทดสอบครั้งเดียว — ห้าม peek แล้วหยุดทันทีที่ p < 0.05
    peeking ทำให้ false positive สูงเกิน α มาก
  5. ถ้า Hamtaro “อยากได้เงินเร็ว” จริง ๆ → ใช้ multi-armed bandit (ε-greedy / Thompson sampling) แทน A/B test แบบ fixed-horizon
    bandit ค่อย ๆ ส่งคนไปเวอร์ชันที่ดีกว่าระหว่างทดลอง ลด regret แต่ให้ข้อสรุปทางสถิติอ่อนกว่า
