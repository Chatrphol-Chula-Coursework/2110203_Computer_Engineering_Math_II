01 Testing, the frequentist way — ความต่างที่เห็นเป็นของจริงไหม

What: วิธีตัดสินใจจากข้อมูล — สมมติค่าตั้งต้น (null hypothesis) แล้วตรวจทางสถิติว่าข้อมูลเข้ากับมันหรือไม่ · Why: ความต่างเล็ก ๆ อาจเกิดจากความบังเอิญล้วน ๆ

02 Null Hypothesis Significance Testing — ส่วนประกอบ

ส่วนประกอบความหมาย
H₀ null hypothesisค่าตั้งต้น — สิ่งที่คาด/ง่ายที่สุด (“ไม่มีผล”, “ไม่ต่างกัน”)
HA (หรือ H₁) alternativeสิ่งที่เรายอมรับถ้าปฏิเสธ H₀
Test statistic X“บางอย่าง” ที่คำนวณจากข้อมูล (เป็น RV) เช่น z, t
Null distributionการแจกแจงของ X เมื่อสมมติว่า H₀ จริง
Rejection region Rถ้า X ตกใน R → ปฏิเสธ H₀ (ข้อมูล “ไม่น่าจะ” มาจาก null distribution) · P(X ∈ R | H₀) ≤ α
Non-rejection regionถ้า X ตกตรงนี้ → ปฏิเสธ H₀ ไม่ได้ (ไม่ได้แปลว่า H₀ จริง)
Critical value cเส้นแบ่งสองบริเวณ · one-sided: P(X ≥ c | H₀) = α เช่น z0.05 = quantile 0.95 = 1.645
p-valueสมมติ H₀ จริง: ความน่าจะเป็นที่จะเห็นข้อมูลสุดโต่งอย่างน้อยเท่าที่เห็น · ปฏิเสธเมื่อ p ≤ α

03 Type of error · significance level vs power

H₀ จริงHA จริง
Reject H₀Type I error (false positive) — prob = αถูก — prob = power = 1 − β
ไม่ reject H₀ถูก — prob = 1 − αType II error (false negative) — prob = β

Significance level = “False hope”

α = P(type I error) = P(reject H₀ | H₀) — ลดโอกาสสรุปผิดว่า H₀ ไม่จริง

Power = “ความสามารถหาสมบัติจริง”

1 − P(type II error) = P(reject H₀ | HA) — ถ้า HA จริง โอกาสที่เราจะเจอ

ตั้ง α เท่าไรดี? ขึ้นกับต้นทุนของการผิด

Situation 1: โกโก้ 72%

H₀: ช็อกโกแลตล็อตนี้ดี (cocoa ≥ 72%) · HA: ล็อตเสีย · Type I = ทิ้งล็อตดี (เสียค่าวัตถุดิบ ไม่ใช่หายนะ) · Type II = ปล่อยล็อตเสีย (ลูกค้าไม่พอใจ เสียแบรนด์ recall) → α สูงได้ เช่น 0.1 เพื่อเพิ่ม power

Situation 2: ลายนิ้วมือ

H₀: ผู้ต้องสงสัยบริสุทธิ์ · HA: ผิด · Type I = ลายนิ้วมือ “ตรง” ทั้งที่ไม่ตรง → คนบริสุทธิ์ติดคุก · Type II = ปล่อยคนผิด → α ต่ำ เช่น 0.01

04 Designing a hypothesis test — 5 ขั้น

0. มีสิ่งที่จะทดสอบHA
1. เลือก H₀
2. one- / two-sided
3. เลือก test statistic
4. α → rejection region0.1, 0.05, 0.01

Example 1 (สไลด์). Hamtaro อยากรู้ว่า Instagram Reel ที่มีซับไตเติลดีกว่าไม่มีซับไหม — อธิบายขั้นตอนทำ NHST, การทดลอง และส่วนประกอบของ NHST

  1. การทดลอง: ทำ Reel หลายคู่ที่เนื้อหาเหมือนกัน สุ่มว่าคนดูเห็นเวอร์ชันมีซับหรือไม่มี (หรือสุ่มสลับโพสต์ คุมเวลาโพสต์/หัวข้อ)
    สุ่ม = ตัด confounder
  2. Metric: สัดส่วนคนที่ดูจบ (หรือ like/share rate) ต่อผู้ชม → ข้อมูล 0/1
    นิยามก่อนเก็บข้อมูล
  3. H₀: psub ≤ pno   vs   HA: psub > pno → one-sided (สนใจว่า “ดีกว่า”)
  4. Test statistic: two-proportion z (ถ้าวัดเวลาดูเฉลี่ย → two-sample t) · null distribution N(0, 1)
    n ใหญ่ ≥ 5 ทั้ง yes/no ต่อกลุ่ม
  5. α = 0.05 → reject ถ้า z > 1.645 · คำนวณ n จาก MDE + power 0.8 ก่อนเริ่ม แล้วทดสอบครั้งเดียวตอนจบ
    ดูรายละเอียดใน Lecture 03 A/B testing

05 z-test และ t-test ทั้งสามแบบ

Testใช้เมื่อTest statisticNull distribution
z-testเทียบ mean กับค่าที่สมมติ, รู้ σ (ข้อมูล Normal หรือ n ใหญ่ตาม CLT)z = (x̄ − μ₀)/(σ/√n)N(0, 1)
One-sample tเทียบ mean กับค่าที่สมมติ, ไม่รู้ σt = (x̄ − μ₀)/(s/√n), s² = Σ(xᵢ − x̄)²/(n − 1)t(n − 1)
Two-sample tเทียบ mean สองชุด อิสระ, ไม่รู้ σ แต่เท่ากันt = (x̄ − ȳ)/(sp√(1/n + 1/m)), sp² = [(n−1)sx² + (m−1)sy²]/(n+m−2)t(n + m − 2)
Paired tข้อมูลเป็นคู่ จำนวนเท่ากันwᵢ = xᵢ − yᵢ แล้วทำ one-sample t บน w กับ H₀: μ₀ = 0t(n − 1)
critical value ของ t ใหญ่กว่า z เสมอ → ต้องการหลักฐานมากกว่าเมื่อไม่รู้ σ

Quiz 6 (สไลด์). GCC กับ Clang ประสิทธิภาพต่างกันไหม? เวลารัน (วินาที) GCC: 12.5, 13.1, 12.8, 13.5, 12.9 · Clang: 11.8, 12.2, 11.9, 12.5, 12.1

  1. H₀: μGCC = μClang vs HA: μGCC ≠ μClang · two-sample t-test (two-sided)
    สองชุดวัดแยกกัน ไม่รู้ σ
  2. x̄ = 64.8/5 = 12.96 , ȳ = 60.5/5 = 12.10
  3. s₁² = 0.552/4 = 0.138 , s₂² = 0.30/4 = 0.075
    Σ(x − x̄)²: 0.2116+0.0196+0.0256+0.2916+0.0036 = 0.552
  4. sp² = (4·0.138 + 4·0.075)/8 = 0.1065 , SE = √(0.1065 · 2/5) = 0.2064
  5. t = (12.96 − 12.10)/0.2064 = 4.17 , df = 8 , p = 0.0031
    t0.025, 8 = 2.306 → ปฏิเสธ H₀: GCC ช้ากว่าอย่างมีนัยสำคัญ

06 Two-proportion z-test — สองกลุ่มมีสัดส่วนเท่ากันไหม

p̂₁ = x₁/n₁ , p̂₂ = x₂/n₂ pooled p̂ = x₁ + x₂n₁ + n₂ z = p̂₁ − p̂₂√(p̂(1 − p̂)(1/n₁ + 1/n₂)) ≈ N(0, 1)

ใต้ H₀: p₁ = p₂ ทั้งสองกลุ่มใช้ p เดียวกัน จึงประมาณจากข้อมูลรวม (pooled) · Normal มาจาก CLT → แต่ละกลุ่มต้องใหญ่พอ: คาดว่ามี “yes” ≥ 5 และ “no” ≥ 5 ในทุกกลุ่ม · กลุ่มเล็กใช้ exact test

    07 Effect size: signal vs noise — และ p-value ใหญ่แปลว่าอะไร

    Cohen's d = |μ₁ − μ₂|σ t = x̄ − μ₀ (signal)s/√n (noise)

    ความต่างยิ่งใหญ่ ยิ่งวัดง่าย · spread σ ยิ่งเล็ก ยิ่งวัดง่าย · n ยิ่งมาก noise ยิ่งเล็ก

    p = 0.6 แปลว่าอะไร

    ผิด: “p-value ใหญ่ พิสูจน์ว่าไม่มีผล และ H₀ จริง”
    ถูก: “การทดลองไม่ได้ให้หลักฐานพอจะเชื่อว่า H₀ ผิด” → inconclusive
    สาเหตุที่เป็นไปได้: H₀ จริง · n เล็กเกิน (power ต่ำ) · ข้อมูล noisy เกิน · effect จริงเล็กมาก

    Edge cases

    • x̄ = μ₀ พอดี: two-sided p = 1.0, one-sided p = 0.5 (ข้อสอบ 2024 ข้อ 1.5!)
    • x̄ < μ₀ ใน right-sided test → p > 0.5
    • p = 0 เป็นไปไม่ได้ทางทฤษฎี (แค่เล็กจนคำนวณไม่ได้)
    • s = 0 → ไม่ต้องใช้ NHST (และคำนวณไม่ได้)
    • N → ∞: ความต่างจิ๋วแค่ไหนก็ significant — แต่ “statistically significant” ≠ “practically significant” (โอเคกับดีขึ้น 0.001% ไหม?)

    08 The peril of p-values — p-hacking · base rate fallacy · low power

    P-hacking

    ลองวิเคราะห์ไปเรื่อย ๆ จนได้ p ≤ 0.05 — xkcd 882 (เยลลี่ 20 สี): ทดสอบ 20 ครั้ง ผิด 1 ครั้งก็คือนิยามของ α = 0.05 เอง · “วิธี” ที่ห้ามทำ: เพิ่ม subject ไปเรื่อย ๆ, แปลงข้อมูล, วิเคราะห์เฉพาะ subset, ตัด outlier, เพิ่มตัวแปร, เปลี่ยน control group, ปรับข้อมูล, เปลี่ยน outcome, เปลี่ยน test

    Two most common fallacies

    • #1 “งานที่ตีพิมพ์ผิด 5%” — ผิด! α คือ error rate ของวิธี ไม่ใช่ของผลที่ตีพิมพ์ (ไม่ได้ตีพิมพ์ทุกการทดลอง + base rate)
    • #2 “p-value คือความน่าจะเป็นที่ผมผิด” — ผิด! อยากรู้ P(H₀ จริง | data) แต่ p-value คือ P(data | H₀ จริง)

    Base rate fallacy (สไลด์): ยา 100 ตัว

    สไลด์: 10 ตัวได้ผล เจอ 8 (power 0.8) · 90 ตัวไม่ได้ผล false positive ~5 (α 0.05) → เห็น “ได้ผล” 13 ตัว แต่ได้ผลจริงแค่ 8/13 = 62% (ผิด 38%) เพราะ base rate ต่ำ

    Low power (สไลด์): ทดสอบเหรียญ H₀: θ = 0.5 ด้วยการโยน n ครั้ง

    สไลด์: n = 10 reject ที่ 0–2 หรือ 8–10 หัว (α ≈ 0.11) · power ที่ θ = 0.1 ≈ 0.93 แต่ที่ θ = 0.4 แค่ ≈ 0.18 · n = 1000 power ≈ 1.0 ทั้งคู่

    09 Multiple testing correction — FWER vs FDR

    1. 1 การทดลอง: P(false positive) = 1 − 0.95 = 0.05
      α = 0.05
    2. 20 การทดลอง: P(false positive ≥ 1) = 1 − 0.9520 ≈ 0.64
      ถ้าอิสระกัน
    3. Correction 1 · FWER (Family-Wise Error Rate) — เป้า: P(false positive ≥ 1) ≤ α (zero-tolerance) · Bonferroni: αnew = α/m — ง่าย แต่ conservative มาก เสีย power
      m = จำนวนการทดลอง
    4. Correction 2 · FDR (False Discovery Rate) — เป้า: E[false discoveries / total discoveries] ≤ q · มาตรฐานใน large-scale testing
      false discovery = ปฏิเสธ H₀ ทั้งที่ไม่ควร (คิดว่าค้นพบของใหม่แต่ไม่ใช่)

    Benjamini–Hochberg procedure

    1. เรียง p-value จาก m การทดลอง: p₍₁₎ < p₍₂₎ < … < p₍m₎
    2. แต่ละ p₍i₎ คำนวณ critical value q × i/m
    3. หา p₍k₎ ตัวที่ใหญ่ที่สุดที่ ≤ critical value ของมัน
      ไม่ใช่ตัวแรกที่ผ่าน!
    4. ประกาศ p₍1₎, …, p₍k₎ ว่า significant ทั้งหมด
      แม้บางตัวก่อนหน้าจะเกิน critical ของมันเองก็ตาม
    ตัวอย่างสไลด์ (q = 0.05): 0.003, 0.023, 0.027 significant · Bonferroni (0.05/5 = 0.01) จะผ่านแค่ 0.003 — B-H ได้ power มากกว่า

    Testใช้เมื่อ

    χ² goodness of fitเทียบจำนวนในแต่ละหมวด (categorical) กับจำนวนที่คาดไว้

    อื่น ๆANOVA (เทียบ mean มากกว่า 2 กลุ่ม) · Welch's t (variance ไม่เท่ากัน) · χ² homogeneity, likelihood-ratio test

    χ² goodness of fit. ทดสอบหน้าแรก 3 แบบ ถาม 300 คนว่าชอบแบบไหน · ผิด: t-test (ข้อมูล categorical ไม่มี mean) · ถูก: Σ(O − E)²/E ~ χ²(k − 1), E = 100, df = 2

    สไลด์ไม่ได้ให้จำนวนจริง — ลองใส่เอง (ค่าเริ่มต้นเป็นตัวอย่างสมมติ):

    McNemar. 40 queries ก่อน/หลังเพิ่ม index: Pass→Pass 20, Fail→Pass 9, Pass→Fail 2, Fail→Fail 9 · ผิด: two-proportion z (วัดของชุดเดิมสองครั้ง ไม่อิสระ) · ถูก: McNemar — มีแค่ 11 ตัวที่เปลี่ยนที่มีข้อมูล

    1. H₀: เปลี่ยนไปทางไหนก็เท่ากัน (เหรียญเที่ยง)
    2. X = # pass→fail ~ Bin(11, 0.5): P(X ≤ 2) = 0.033
      exact
    3. หรือ (B − C)²/(B + C) = (9 − 2)²/11 = 4.45 ~ χ²(1) → p = 0.035 (two-sided)
      index ใหม่ช่วยอย่างมีนัยสำคัญ

    Wilcoxon signed-rank. ผลต่าง 40, 40, −5, 90, 40, 20 (ms) — 6 ค่าน้อยเกินจะเช็ก Normality · ผิด: paired t-test · ถูก: ใช้ rank แทนค่า

    1. rank ของ |d|: 5 → 1, 20 → 2, 40, 40, 40 → 4 ทุกตัว (เฉลี่ยของ 3, 4, 5), 90 → 6
      ค่าเท่ากันใช้ rank เฉลี่ย
    2. W⁻ = ผลรวม rank ของผลต่างที่ติดลบ = 1
      มีแค่ −5
    3. ใต้ H₀ ทุกแบบเครื่องหมาย 2⁶ = 64 แบบเท่ากัน → P(W⁻ ≤ 1) = 2/64 = 0.031
      W⁻ = 0 (ไม่มีลบ) หรือ W⁻ = 1 (ลบแค่ตัว rank 1)
    4. n ใหญ่: z = (W⁻ − n(n+1)/4)/√(n(n+1)(2n+1)/24) ~ N(0,1) · paired t ให้ p = 0.016

    Fisher transformation. วัด r = 0.5 จาก n = 28 คู่ — correlation จริงไหม? · ผิด: คิดว่า r เป็น Normal (spread ขึ้นกับ ρ) · ถูก: z = atanh(r)·√(n − 3)

    1. atanh(r) = ½ ln((1 + r)/(1 − r)) = ½ ln 3 = 0.549
    2. z = 0.549 × √25 = 2.75 → เทียบ N(0,1)
      การทดสอบ correlation กลายเป็น z-test
    3. one-sided p = 0.003 → ปฏิเสธ H₀: ρ = 0
    ระวัง assumption! ข้อมูล Normal + variance เท่ากันไหม (z/t-test)? — ดู histogram (เบ้? outlier?) · test ทางการ: Shapiro–Wilk (normality), Levene (equal variance) · เช็กความอิสระ · อิสระหรือเป็นคู่?

    11 Choosing a test — หาสูตรที่ตรงกับคำถาม

    3 คำถามก่อนเลือก

    1. คำถามวิจัยคืออะไร — เทียบ mean? สัดส่วน/ความสัมพันธ์? correlation?
    2. ข้อมูลเป็นแบบไหน — ต่อเนื่อง? categorical? กี่กลุ่ม? อิสระหรือคู่?
    3. ผ่าน assumption ไหม — normality, equal variance

    Basic flowchart

    เทียบสองกลุ่ม? → คู่ → paired t · อิสระ → two-sample t
    เทียบกลุ่มเดียวกับ population? → รู้ variance → z-test · ไม่รู้ → one-sample t

    Which test?คำตอบ
    1. ส่วนสูงเฉลี่ยคนไทย 153 cm · ห้องนี้ 280 คน เฉลี่ย 156 cm — สูงกว่า population ไหมOne-sample t-test (right-sided) เทียบ x̄ กับ μ₀ = 153 · ไม่รู้ σ ของประชากร ใช้ s ของห้อง (n = 280 ใหญ่ → t ≈ z) — คำนวณใน Practice 1
    2. คะแนน CEM2 ดีขึ้นกว่า CEM1 ไหมPaired t-test — นักเรียนคนเดียวกันมีคะแนนสองวิชาเป็นคู่ · w = CEM2 − CEM1, H₀: μw = 0 vs HA: μw > 0 (ถ้าผลต่างไม่ Normal → Wilcoxon)
    3. 10 คนให้คะแนน 5 ภาพ (1–5 ดาว) — ทุกภาพคะแนนเฉลี่ยเท่ากันไหมเทียบ mean มากกว่า 2 กลุ่ม → ANOVA (คนเดียวให้ครบ 5 ภาพ → repeated-measures ANOVA; คะแนนเป็นลำดับ 1–5 → Friedman test) · ถ้าจับคู่ t-test ทีละคู่ (10 คู่) ต้องแก้ multiple testing

    12 The bigger picture — interventional inference & RCT

    ทำไมต้อง significance testing

    เป้าหมาย: ความต่างที่เห็นเป็นของจริงไหม · use case หลัก: interventional inference — เปลี่ยนปัจจัยหนึ่งแล้วทำให้อีกปัจจัยเปลี่ยนหรือไม่ (การศึกษามีผลต่อรายได้ไหม?) · ปัญหา: การสังเกตอย่างเดียวไม่พอ — มี hidden confounder (สถานะทางสังคม → การศึกษา และ → รายได้)

    Randomized Controlled Trial (RCT)

    ข้อมูลแสดงโลก “อย่างที่เป็น” แต่ผลของการกระทำอยู่ใน “โลกที่ถูกเปลี่ยน” ซึ่งเราไม่มีข้อมูล · ตัดลูกศรจาก confounder ด้วยการ do(Education) แบบโยนเหรียญ → สถานะสังคมไม่มีผลต่อว่าใครได้ treatment · เป็นมาตรฐานของ social studies และคือ A/B testing (Lecture 03)

    Good practice

    • คำนวณ sample size ก่อนเริ่มการทดลองเสมอ
    • อธิบายวิธีให้ครบ (ได้ statistic มาอย่างไร ใช้ test อะไร)
    • ถ้าไม่ต้องตัดสินใจจาก test ไม่จำเป็นต้องทำ — เล่าเรื่องด้วย distribution plot แทน
    • ระวังคำว่า “significant” ในงานเขียนเทคนิค · แสดง distribution ของข้อมูล ไม่ใช่แค่ mean

    Key takeaways

    • NHST คือวิธีมาตรฐานในการพูดถึงความแข็งแรงของหลักฐาน — แยก signal จาก noise
    • มีกับดักเยอะ: p-value trap, “not significant” fallacy, p-hacking, multiple comparisons, assumption, edge cases

    13 Let's practise! — เฉลยทีละขั้น

    Practice 1. ส่วนสูงเฉลี่ยคนไทย 153 cm · ห้องนี้ 280 คน เฉลี่ย 156 cm, SD = 10 · สูงกว่าอย่างมีนัยสำคัญที่ α = 0.05 ไหม?

    1. H₀: μ = 153 vs HA: μ > 153 (one-sided) · one-sample t-test
      ไม่รู้ σ ประชากร
    2. s² = 100 × 280/279 = 100.36 → s = 10.02
      สไลด์ถือว่า SD = 10 หารด้วย n แล้วแปลงเป็น sample variance (หาร n − 1)
    3. t = (156 − 153)/(10.02/√280) = 3/0.5988 = 5.01 , df = 279
    4. t0.05, 279 ≈ 1.650 → 5.01 > 1.65 → ปฏิเสธ H₀ (p ≈ 5 × 10⁻⁷)
      ห้องนี้สูงกว่าค่าเฉลี่ยประเทศอย่างมีนัยสำคัญ (แต่ไม่ใช่ random sample ของคนไทย!)

    Practice 2. ผลผลิตข้าวต่อไร่ ~ N(7000, 150²) kg · นา 15 ไร่ ได้เฉลี่ย 7077 kg · ชนะค่าเฉลี่ยที่ α = 0.05 ไหม?

    1. H₀: μ = 7000 vs HA: μ > 7000 · z-test (รู้ σ = 150)
    2. z = (7077 − 7000)/(150/√15) = 77/38.73 = 1.988
    3. z0.05 = 1.645 → 1.988 > 1.645 → ปฏิเสธ H₀ ชนะค่าเฉลี่ย (p = 0.023)
      ถ้าเป็น two-sided (1.96) ก็ยังผ่านแบบเฉียด

    Practice 3. เลือกทำเลร้าน: A ขายได้ [5, 3, 5, 6, 5, 9, 15] · B ขายได้ [4, 3, 6, 4, 4, 20, 25] · B ดีกว่า A ที่ α = 0.1 ไหม? ถ้าเช่าที่ละ 4 สัปดาห์ (ยอดขายแต่ละสัปดาห์ซ้ำเดิม) ล่ะ?

    1. H₀: μB ≤ μA vs HA: μB > μA · two-sample t-test one-sided
    2. x̄A = 48/7 = 6.857 , x̄B = 66/7 = 9.429 , sA² = 16.143 , sB² = 82.619
    3. sp² = (6 · 16.143 + 6 · 82.619)/12 = 49.381 , SE = √(49.381 · 2/7) = 3.756
    4. t = (9.429 − 6.857)/3.756 = 0.685 , df = 12 , t0.1, 12 = 1.356 → ไม่ปฏิเสธ H₀ (p = 0.25)
      B noisy มาก (20, 25 สองวัน) — variance กลบ signal
    5. 4 สัปดาห์ (n = 28 ต่อทำเล, mean เท่าเดิม): sA² = 16.143 · 24/27 = 14.349 , sB² = 82.619 · 24/27 = 73.439
      Σ(x − x̄)² คูณ 4 แต่หารด้วย 27
    6. sp² = 43.894 , SE = √(43.894 · 2/28) = 1.771 , t = 2.571/1.771 = 1.452 , df = 54
    7. t0.1, 54 = 1.297 → 1.452 > 1.297 → ปฏิเสธ H₀ (p = 0.076)
      effect เท่าเดิม แต่ n มากขึ้น → SE เล็กลง → significant · (assumption “ยอดเหมือนเดิมทุกสัปดาห์” ไม่สมจริง — แค่แสดงผลของ n)
