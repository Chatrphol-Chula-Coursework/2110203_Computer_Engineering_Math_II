01 จากโมเดลสู่ข้อมูล — simulation & sampling

Blueprint (โมเดล): น้ำหนักเมล็ดทานตะวันสด ~ N(5, 0.5²) → Virtual factory (simulation): สร้างเมล็ดเสมือน 1,000 เมล็ด → Product (sample): [5.1 g, 4.4 g, 5.8 g, 4.9 g, …] · NumPy/SciPy มีฟังก์ชันสุ่มให้แล้ว แต่ถ้าการแจกแจงไม่มาตรฐานล่ะ? → หัวข้อ 02

ค่าเฉลี่ย / SD ของ sample ใกล้ค่าในโมเดลเมื่อจำนวนมากขึ้น (LLN) — นี่คือเหตุที่เราใช้ sample ประมาณค่าจริงได้

02 Inverse transform sampling — ใช้ CDF ย้อนกลับ

คอมพิวเตอร์สุ่มได้จริง ๆ แค่ U ~ Uniform(0, 1) แต่ CDF ของทุกการแจกแจงมีค่าอยู่ใน [0, 1] พอดี! ดังนั้นแทนที่จะเดิน x → ความน่าจะเป็น ให้เดินถอยหลัง ความน่าจะเป็น → x

  1. สุ่ม u ~ U(0, 1)
    ตัวสุ่มพื้นฐานที่ทุกภาษามี
  2. วาง u บนแกน y ของ CDF เป้าหมาย
    u คือ “ความน่าจะเป็นสะสม”
  3. ลากแนวนอนไปชนเส้น CDF แล้วลากลงแกน x
    ช่วงที่ CDF ชันคือที่ pdf สูง — u ตกช่วงนั้นบ่อย → ได้ x แถวนั้นบ่อย
  4. x = F−1(u) คือตัวอย่างสุ่มที่มีการแจกแจง F
    เหตุผล: P(F−1(U) ≤ x) = P(U ≤ F(x)) = F(x)

Sampling example (สไลด์). pdf fX(x) = 2x (0 ≤ x ≤ 1) หา FX−1(u)

CDF: F(x) = ∫0x 2t dt = x² → ตั้ง u = x² → F−1(u) = √u · ส่วน Exponential: u = 1 − e−λx ⇒ x = −ln(1 − u)/λ เช่น λ = 1, u = 0.632 ได้ x ≈ 1 ชั่วโมง

03 Likelihood & Maximum Likelihood Estimation — θ ไหนทำให้ข้อมูลที่เห็น “ไม่น่าแปลกใจ” ที่สุด

Maxwell ลองเทคนิคอ่านเร็ว 100 หน้า อ่านจบภายใน 1 นาทีได้ 55 หน้า พลาด 45 หน้า — อัตราสำเร็จ p ที่น่าจะเป็นที่สุดคือเท่าไร?

ศัพท์ในตัวอย่างนี้
Experimentลองอ่านเร็ว 100 หน้า นับว่าสำเร็จกี่หน้า
Data Dผลที่ได้: 55 หน้า
Parameter of interest θp ที่ไม่รู้
Likelihood L(θ; D) = P(D | θ)P(55 fast pages | p) = C(100, 55) p55(1 − p)45

Likelihood เป็นฟังก์ชันของ θ (ข้อมูลตรึงไว้) — ไม่ใช่การแจกแจงของ θ จึงไม่จำเป็นต้องรวมได้ 1 · MLE: θ̂MLE = argmaxθ P(D | θ) (หมวก ^ = “ค่าประมาณ”)

04 หาจุดสูงสุดด้วยอนุพันธ์ + log-likelihood — ทำทีละขั้น

Interlude: หาจุดสุดขีด

f(x) = x³ − 3x + 11 · f′(x) = 3x² − 3 = 0 ⇒ x = ±1
f″(x) = 6x: f″(1) = 6 > 0 → min (f = 9) · f″(−1) = −6 < 0 → max (f = 13)

ทำไมใช้ log

  • ln เป็นฟังก์ชันเพิ่มเสมอ (monotonic) → θ ที่ทำให้ ln L สูงสุด = θ ที่ทำให้ L สูงสุด
  • เปลี่ยนผลคูณเป็นผลบวก: ln(ab) = ln a + ln b, ln ab = b ln a → อนุพันธ์ง่ายขึ้นมาก
  • กัน underflow: คูณความน่าจะเป็นเล็ก ๆ หลายพันตัวจะกลายเป็น 0 ในคอมพิวเตอร์

วิธีที่ 1 · อนุพันธ์ตรง ๆ (product rule)

  1. d/dp [ C p55(1 − p)45 ] = 0 , C = C(100, 55)
    C ไม่ขึ้นกับ p — ทิ้งได้
  2. 55p54(1 − p)45 − 45p55(1 − p)44 = 0
    (uv)′ = u′v + uv′ และ d/dp(1 − p)45 = −45(1 − p)44
  3. 55p54(1 − p)45 = 45p55(1 − p)44
    ย้ายข้าง
  4. 55(1 − p) = 45p
    หารด้วย p54(1 − p)44
  5. 55 = 100p ⇒ p̂MLE = 0.55
    = สัดส่วนที่สำเร็จจริง ตรงกับสัญชาตญาณ

วิธีที่ 2 · log-likelihood (ง่ายกว่า)

  1. ln L = ln C(100, 55) + 55 ln p + 45 ln(1 − p)
    log ของผลคูณ = ผลบวกของ log
  2. d/dp ln L = 55p − 451 − p = 0
    ค่าคงที่หายไป · d/dp ln(1 − p) = −1/(1 − p)
  3. 55(1 − p) = 45p
    คูณไขว้
  4. p̂MLE = 0.55 · ทั่วไป p̂ = k/n
    ได้ค่าเดียวกัน — ต่อไปใช้วิธีนี้เสมอ

05 ตัวอย่าง MLE — Exponential และ Geometric

Likelihood ของ 1 ข้อมูลสูตรMLE จาก n ข้อมูล
Binomial (discrete → ใช้ pmf)p(k | n, p) = C(n,k) pk(1 − p)n−kp̂ = k/n
Geometric (k = จำนวนครั้งที่ล้ม)p(k | p) = (1 − p)k pp̂ = n / (n + Σki) = #สำเร็จ / #ครั้งทั้งหมด
Exponential (continuous → ใช้ pdf)f(x | λ) = λe−λxλ̂ = n / Σxi = 1/x̄
Normalf(x | μ, σ) = e−(x−μ)²/2σ²/√(2πσ²)μ̂ = x̄ , σ̂² = (1/n)Σ(xi − x̄)²

Example 1 (สไลด์). เครื่องจักรในโรงงานของ Hamtaro มีอายุการใช้งานแบบ exponential เสียหลัง 2, 3, 1, 3, 4 ปี (อิสระกัน) ประมาณพารามิเตอร์

  1. f(x₁, …, x₅ | λ) = Π λe−λxi = λ5 e−λ(x₁+⋯+x₅)
    อิสระ → joint pdf = ผลคูณ
  2. ข้อมูลรวม = 2 + 3 + 1 + 3 + 4 = 13 → L(λ) = λ5e−13λ
    แทนค่าข้อมูลจริง
  3. ln L = 5 ln λ − 13λ
    ln ex = x
  4. d/dλ ln L = 5/λ − 13 = 0 ⇒ λ̂ = 5/13 ≈ 0.385 ต่อปี
    = 1/x̄ (อายุเฉลี่ย 2.6 ปี)

Example 2 (สไลด์). Cappy หัดทำหมวกแบบใหม่ จำนวนครั้งที่ล้มก่อนสำเร็จเป็น Geometric — 3 แบบหมวก สำเร็จในครั้งที่ 1, 1, 3

  1. จำนวนครั้งที่ล้ม = 0, 0, 2
    สำเร็จครั้งที่ 3 = ล้ม 2 ครั้งก่อน (ระวังนิยาม!)
  2. L(p) = (1 − p)0p · (1 − p)0p · (1 − p)2p = (1 − p)2p3
    ผลคูณของ pmf ทั้งสาม
  3. d/dp [2 ln(1 − p) + 3 ln p] = −21 − p + 3p = 0
    log-likelihood
  4. p̂ = 3/5 = 0.6
    สมเหตุสมผล: สำเร็จ 3 ครั้งจากการลองทั้งหมด 1 + 1 + 3 = 5 ครั้ง

06 Estimator ดีแค่ไหน — bias, variance และคุณสมบัติของ MLE

Biasความคลาดเคลื่อนเชิงระบบ

โดยเฉลี่ยแล้วค่าประมาณห่างจากค่าจริงเท่าไร? Unbiased: E[θ̂] = θ

Varianceความคลาดเคลื่อนแบบสุ่ม

ถ้าได้ข้อมูลชุดใหม่ทั้งชุด ค่าประมาณจะเปลี่ยนไปมากแค่ไหน? (กระจายรอบค่าเฉลี่ยของมันเอง)

MLEคุณสมบัติ

  • Consistent — ข้อมูลมากขึ้น θ̂ เข้าใกล้ θ จริง
  • Asymptotically unbiased — ไม่สูง/ต่ำเชิงระบบเมื่อ n ใหญ่ (n เล็กอาจ bias)
  • Asymptotically minimal variance — แม่นที่สุดในบรรดา unbiased estimator เมื่อ n ใหญ่

ทดลอง: ข้อมูล n ตัวจาก N(0, σ² = 4) ประมาณ σ² สองแบบ — MLE σ̂² = (1/n)Σ(x − x̄)² เทียบ sample variance s² = (1/(n−1))Σ(x − x̄)² ทำซ้ำ 4,000 ครั้งแล้วดูการแจกแจงของค่าประมาณ

MLE ของ σ² มี bias E[σ̂²] = n − 1nσ² (ต่ำไปเสมอ เพราะใช้ x̄ ที่ fit กับข้อมูลเอง) แต่ bias → 0 เมื่อ n → ∞ — นี่คือ “asymptotically unbiased” · และทั้งคู่แคบลงเมื่อ n โต (consistent)

07 Bayes theorem & MAP — เมื่อเรามีความรู้เดิม (prior)

P(θ | D) = P(D | θ) · P(θ)P(D) θ̂MAP = argmaxθ P(D | θ) P(θ)
posteriorความเชื่อเรื่อง θ หลังเห็นข้อมูล
likelihoodMLE ใช้แค่ตัวนี้
priorความรู้ก่อนเห็นข้อมูล
evidenceP(D) = Σθ P(D|θ)P(θ) ตัว normalize — ไม่ขึ้นกับ θ

MLE คือกรณีพิเศษของ MAP ที่ prior เป็น uniform · P(D) ทิ้งได้ตอนหา argmax แต่ ไม่ใช่ค่าคงที่ในตัวมันเอง — ข้อมูลชุดใหม่ D′ ก็ได้ P(D′) ≠ P(D)

Example 3 (สไลด์). Hamtaro หาลูกโอ๊กที่ Boss ซ่อน — จุดซ่อน 3 แบบ: A เจอ 80%, B 50%, C 40% · Boss ใช้ A 40%, B 40%, C 20% ของเวลา · Hamtaro ค้นจุดใหม่ 5 ครั้ง เจอ 2 ครั้ง — หา MAP

ปรับ n, k และ prior ได้ด้านล่าง · กด “Example 5” = Pashmina บอกว่าเป็นจุดแบบ A แน่นอน (prior 100%)

Example 4 (สไลด์). หลังค้น 5 ครั้งแรก โอกาสเจอในการค้นครั้งถัดไปเป็นเท่าไร?

P(Acorn | D) = Σθ P(Acorn | θ) P(θ | D) = 0.8(0.0954) + 0.5(0.5825) + 0.4(0.3221) ≈ 0.496 — ไม่เท่ากับ θ̂MLE = 0.4 และไม่เท่ากับ θ̂MAP = 0.5 เพราะเป็นการผสม likelihood กับ prior ทั้งหมด (posterior predictive) · ค่านี้แสดงสดในกล่อง “โอกาสเจอครั้งถัดไป” ด้านบน

ข้อควรระวังของ MAP: prior มีอิทธิพลมาก (Example 5: prior 100% ทำให้ข้อมูลไม่มีผลเลย ต่อให้ค้น 30 ครั้งเจอ 0 ครั้ง) — ต้องอธิบายได้ว่า prior มาจากไหน และถ้า Pashmina ผิดล่ะ?

08 Credible interval vs confidence interval — มั่นใจแค่ไหน

BayesianCredible interval

  • ช่วง [a, b] ที่ P(a ≤ θ ≤ b | D) = 0.95
  • เป็นความน่าจะเป็นของ θ เมื่อเห็นข้อมูลแล้ว — พูดว่า “θ อยู่ในช่วงนี้ 95%” ได้ตรง ๆ
  • มีได้หลายช่วง (เช่น equal-tailed, highest density)

FrequentistConfidence interval

  • ทำการทดลองซ้ำหลายครั้ง 95 จาก 100 ครั้งช่วงจะคร่อมค่าจริง
  • เป็นข้อความเกี่ยวกับอัตราสำเร็จระยะยาวของวิธีการ ไม่ใช่ของช่วงใดช่วงหนึ่ง
  • ดูการจำลองในหน้า LLN & CLT หัวข้อ 06

เสริม (ต่อยอดจากสไลด์): ถ้า θ ต่อเนื่อง เช่นอัตราสำเร็จ p ∈ [0, 1] ใช้ prior Beta(a, b) — หลังเห็น k สำเร็จจาก n ครั้ง posterior คือ Beta(a + k, b + n − k) (conjugate prior) · prior uniform = Beta(1, 1) ทำให้ MAP = MLE = k/n
